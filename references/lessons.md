# Lessons. One line each: [role] rule (what it cost) (no check: why no script, hook or test can enforce it). Capped, tested.
# Roles: all, orchestrator, critical-read, builder, reviewer, fix, mechanical, walk. A check comes first; a covered line is deleted.
[all] Scratch repros go under a short path in Temp; a long scratchpad path broke tests three times (no check: a hook cannot tell a scratch folder from a project's own)
[all] Write a file with Edit or Write, never node -e: the Bash tool halves a doubled backslash and files may be CRLF on disk, and scripted edits wrecked three files in one epic (no check: node -e also reads, and its writes are invisible to a command-line hook)
[all] Only one Docker run at a time, behind the project's lock; never remove a lock you did not take (three OOM kills, one stolen timing lock) (no check: the lock is the project's, and nothing records who took it)
[all] A background command wakes you only after your turn ends: start none you need before reporting, stop every one you started before handing back, and say so on the handback's background line (a builder re-sent its handback three times at 470k context; two agents left work running in the next epic) (no check: a hook does not see an agent's background tasks)
[orchestrator] After a merge, also run wait-ci.sh --commit on the main of every other repo that runs the merged code: a consumer's main sat red two days after upstream merges and cost about 9M units (no check: which repos consume another is the project's knowledge, not the gate's)
[orchestrator] Check a step file's premise about what another system emits against one real run before dispatch, and send a step that decides a policy to the critical read: "node --test prints its failing test" was false and cost a review round and three PRs; run a rule you decide over the real data before a fixer gets it (an id-length limit failed two published ids) (no check: a premise is prose)
[orchestrator] Before ruling on wording a user sees, grep every place that asserts it (unit tests, browser tests, smoke checks); one date ruling, made call site by call site, cost one PR three rounds (no check: which strings a ruling touches is not known until it is made)
[orchestrator] A port step names its source as the commits on the source repo's main, fix rounds included, and the tests to carry over; a port of the pre-fix commit cost a round (no check: a step file does not mark itself a port)
[orchestrator] Give every agent the orchestrator-owned artefacts and rulings once, up front, each input by path: the run folder, the test command, the ref to restore, a ready fixture, a live try's cost (six handbacks in one epic asked for one of these) (no check: what an agent will need is not in the dispatch)
[orchestrator] A consumer starts early only against a seam written in the settlements in its exact shape, told which suites cannot go green until its producer lands; a seam written as "unchanged" left a coupling check conditional (no check: a seam's shape is prose)
[orchestrator] A behaviour that rests on a live provider gets one live probe before its step closes, and its fix starts from a captured request: stubbed tests passed a reply that went 0 of 1 live, and two guessed causes were wrong (no check: what rests on a live provider is a judgement)
[orchestrator] Every fix round's diff gets a review-small (about 0.1M units): a fix round replaced a complete reply with a cut-off one, and only that round's review caught it (no check: the gate cannot tell which reviewer read which push)
[orchestrator] The maintainer's own session with what shipped is a walk; schedule it before calling a phase done (thirty minutes found seven defects, one the contract failing live) (no check: the session is the maintainer's)
[orchestrator] A findings file quotes the reviewer and any ruling it touches word for word: a paraphrase naming one of two commands, and an "or otherwise" against a ruling, each cost a round (no check: a script cannot tell a quote from a paraphrase)
[orchestrator] A handoff logged yes ends the session: tell the maintainer and dispatch nothing more; paste the handoff-decision line --self prints, verbatim (three yes decisions in one epic were followed by more turns, to a 428k peak and 22.7M units) (no check: the dispatch hook cannot read run.md)
[orchestrator] Split a very large diff's review by concern, one reviewer each (no check: concerns are a reading of the diff)
[orchestrator] Reviewers found something on nearly every PR; skipping one is logged in the status line, never silent (no check: the gate does not know which PRs were reviewed)
[orchestrator] A Workflow gives each agent the user's triggering message as its first turn; never use one for an agent whose prompt must be only its brief (an eval subject obeyed the relayed message) (no check: no hook runs on a Workflow's own agents)
[orchestrator] Each wave's status opens with three numbers: units so far, units per merged PR against the history file, and the role with the largest share; one stage took 46% of an epic's units unquestioned (no check: a status is written to the maintainer, not run)
[orchestrator] A stage the epic adds beyond build, review and fix is run both ways on the pilot and judged by a blind reader before it is dispatched again; an untried stage ran 39 times (no check: a stage is a design call)
[orchestrator] Put each recurring must-fix class in the next step file as an acceptance check (no check: the class is named by reading the findings)
[orchestrator] Split a step that holds several new pieces (a format, its migration and its writers; a data object, its tests and a CI check) into one step each: one Opus builder took 12.2M units and three fix rounds, and a four-piece Sonnet step peaked at 312k (no check: what counts as a piece is a reading of the step)
[orchestrator] A pair whose consumer pins the producer's build merges as three PRs: the producer, the consumer, then the pin bump, planned from the start; a kit main went red on merge because its template pinned the previous build (no check: a pin is the project's file)
[orchestrator] A bench that proves a budget runs on a quiet machine, run by you, at a size from a measured growth curve, both sides of each subtraction in the same state: a 2,000-resource bench was killed twice, and a warm-against-cold Argon2 worker read as +65 ms against +18 ms (no check: a bench's states are its author's)
[orchestrator] Rerun only the newest CI run of each workflow: a rerun of a stale run cancelled the current one through its concurrency group (no check: telling a stale run from the newest takes a GitHub call a hook's 10 seconds cannot rely on)
[critical-read] A step that rests on an unmeasured number is a step 0: one spike cancelled a step worth 71k tokens and 4 minutes (no check: which numbers are measured is a reading)
[critical-read] Set up the local fast loop first; a host runner removed Docker from the loop and made each check six times faster (no check: the loop is the project's)
[critical-read] Each step names every reader of what it changes, in every repo, grepped by every form it is written in (short form, full form, the constant); five handbacks found a reader missing and a short-form grep missed three writers (no check: readers are found by reading)
[critical-read] Read the reference implementation before ruling what a field means (no check: a ruling is prose)
[critical-read] Give a step that changes several repos one builder per repo, producer first; two single builders each stopped with one repo done, after 5.2M and 5.3M units (no check: a step file does not list its repos in a form dispatch reads)
[builder] Run each new test on the old code before trusting it: four vacuous tests were found only that way (no check: the gate does not run a PR's tests on its base)
[builder] Before you push, run every check CI runs on your changed files: typecheck, format, lint, a test-heading check, a suite that iterates every fixture; one epic lost eight CI rounds to these (no check: CI's checks are each repo's, and a push hook would run them all)
[builder] A test gets its own instance of anything an earlier test can change (an app, a folder, a store); one that shared an app passed locally and went red in CI (no check: shared state is a reading of the test)
[builder] A race probe runs two processes, never two calls in one, and a migration proves every write it needs before its point of no return: an in-process lock hid a non-atomic compare-and-swap (three blockers and a fix round) (no check: a probe's design is the builder's)
[reviewer] Probes, adversarial inputs, primary sources and downstream readers found the defects; broad mutation sweeps found nothing. A change that writes state another layer owns gets a close-and-reopen probe (no check: a review's method is a reading)
[reviewer] A blocker costs the builder 30 minutes to 2 hours; give the input that shows it so nobody rediscovers it (no check: a finding is prose)
[reviewer] Re-review in the same standing worktree (seconds, against 5-8 minutes for a fresh one): read the diff since the last review and rerun the old repros (no check: the review worktree is the project's tool)
[reviewer] Where the PR's claim is a count, recompute it from the primary files; three recomputations found gaps. A PR that hands a change list downstream proves it by applying the list in a scratch worktree (no check: which claims are counts is a reading)
[reviewer] Run a proposed config or lint change before listing it; a lint nit that was never run was wrong (no check: a proposal is prose)
[reviewer] A walk you script to check a PR (a browser demo, a CLI session) is a finding: commit it as a test in that PR's fix round; three reviewers each wrote their own walk of one demo (no check: a reviewer's scratch scripts are not in the PR)
[reviewer] A pin bump is checked against the registry's publish date, at least 14 days old (no check: each registry has its own date API, and the gate does not know which file is a pin)
[reviewer] A workflow step with `shell: bash` runs `bash -e`, so a command that may exit non-zero needs `|| true`; under `pipefail` a reader that stops early (`head`, `awk ... exit`) gives its writer SIGPIPE; probe a job a PR never runs with a stub (a review passed a step that turned main red) (no check: a step's failure modes are a reading)
[fix] Reply to a thread after fixing, resolve only after the push; a resolution is a claim the fix is on the head (no check: a resolution's timing is GitHub's, not a hook's)
[fix] Typecheck (`tsc -b` where the repo has one) before committing: a fix round's untypechecked test turned a PR red, and resetting a pushed commit needs a force push, which is refused (no check: each repo's typecheck is its own)
[fix] Without the repo's toolchain, never assert text you inferred: read the expected text from a CI log or a sibling test first (a PR went red on a guessed message) (no check: where a string came from is not in the diff)
[mechanical] Do not repair or retry a failed command; a half-fix pushed over a red build is worse than the red build (no check: a retry looks like any command)
[walk] Check each finding against the live artefact before reporting it: one of a walk's two findings misread a file that was right (no check: a re-check leaves no trace in the handback)
